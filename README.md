# Omic-seq Analysis Pipelines
This repository collects modular, reproducible bioinformatics workflows for multiple types of high-throughput omics sequencing data.

The whole workflow covers raw data quality control, alignment, quantification, statistical testing and downstream functional interpretation.

## Supported data types
- Transcriptome (RNA-seq)
- Epigenomic sequencing (ChIP-seq / DNA methylation sequencing)
- Other genomic high-throughput sequencing data

## Main tools
FastQC, MultiQC, aligners, feature quantification tools, R, DESeq2, Shell scripting

## Repository structure
Each independent analysis case is placed in an individual folder, including analysis scripts, parameter notes and result interpretation records.
All scripts are self-tested on Linux computing environment.
